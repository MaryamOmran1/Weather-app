# Weather Application

## Overview
This weather application provides users with real-time weather information for a specified city. Users can enter a city name, and the application will display the current temperature, humidity, and wind speed.

## Features
- **Search Functionality**: Users can enter the name of a city to get weather information.
- **Responsive Design**: The application is styled to be visually appealing and user-friendly on various devices.
- **Weather Display**: Shows the current weather conditions, including temperature, humidity, and wind speed.

## Technologies Used
- **HTML**: For structuring the web page.
- **CSS**: For styling the application and making it visually appealing.
- **JavaScript (React)**: For handling dynamic data and user interactions.

## HTML Structure
The HTML structure includes:
- A header for the application title.
- A search container with an input field and a search button.
- A weather card that displays the weather information.
